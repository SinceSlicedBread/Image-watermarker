# Image Watermarker

A desktop application built with Python that allows users to add text watermarks to images through a simple graphical interface. Customise the watermark's text, position, font, and colour, preview the result, and apply it to protect or brand your images.

## Features

- **Image Selection:** Load images for watermarking.
- **Custom Text:** Add personalised text to your images.
- **Position Control:** Choose where the watermark appears.
- **Font Selection:** Select from available font families.
- **Colour Options:** Customise the watermark's text colour.
- **Live Preview:** Preview the watermark before applying it.
- **Automatic Opacity:** Apply a predefined opacity for a consistent watermark appearance.
- **Save Watermarked Images:** Export the finished image.

## Technologies

- Python
- Tkinter and ttk
- Pillow (PIL)

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/SinceSlicedBread/Image-watermarker.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Image-watermarker
   ```

3. Install Pillow:

   ```bash
   pip install Pillow
   ```

4. Run the application:

   ```bash
   python main.py
   ```

*Note: Adjust the script filename if your main Python file has a different name.*

## How to Use

1. Launch the application.
2. Select an image to watermark.
3. Enter your desired watermark text.
4. Choose the font, colour, and position.
5. Preview the result.
6. Apply the watermark and save the finished image.

## Purpose

This project demonstrates Python GUI development, event-driven programming, image manipulation, file handling, and the use of Pillow for processing images.
